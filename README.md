# Metric-Imperial Converter

A full-stack JavaScript application built as part of the **freeCodeCamp Back End Development and APIs** certification. This microservice converts various metric and imperial units and validates inputs using an Express backend and Mocha/Chai testing suites.

## Features

- **Unit Conversion**: Convert between gallons and liters, miles and kilometers, and pounds and kilograms in both directions.
- **Advanced Input Parsing**: Handles whole numbers, decimals, fractions, and double-fractions (with error handling).
- **Default Values**: Automatically defaults to a numerical input of `1` if no number is provided.
- **Automated Testing**: Includes complete unit tests (`tests/1_unit-tests.js`) and functional tests (`tests/2_functional-tests.js`).

## Technologies Used

- **Node.js** & **Express.js** (Backend Framework)
- **JavaScript (ES6+)**
- **Mocha** & **Chai** (Testing Frameworks)
